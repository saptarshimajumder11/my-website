astraOS

astraOS is my own web-based operating system concept, built from scratch with HTML, CSS, and JavaScript. It features a desktop-style interface with draggable windows, built-in apps, a taskbar, a start menu, and interactive controls. The project is an experiment in creating a familiar computer experience entirely inside a web browser while learning how interfaces and web applications work.
